# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

This is a collaborative fiction workspace for "Pacha Story," a mythic-historical narrative grounded in Andean cosmology. The project uses a structured **digital quipu** system to organize story elements:

- **Weavings** (YAML scenes in `WEAVINGS/`) replace traditional chapters—each represents intersections of beings, moments, and meanings
- **Entities** (YAML files in `ENTITIES/`) define presences: human, spirit, place, animal, memory
- **KHIPU_MAP.yaml** is the master index tracking cords (relational threads), knots (transformations), and indices
- **Three Pachas (domains)**: hana (upper/celestial), kay (living/present), ukhu (inner/ancestral)

## Commands

### Update indices after adding/editing Weavings or Entities

```bash
python update_khipu.py
```

The `.githooks/pre-commit` hook runs this automatically on commit.

### Generate quipu visualization

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "Visual Quipu Builder/build_quipu_visual.ps1"
```

Or directly:

```bash
python export_quipu_graph.py --output "Visual Quipu Builder/quipu.svg" --format svg
```

Requires Graphviz `dot` on PATH for SVG/PNG/PDF output.

## Key Vocabulary (Required)

- Use **Weavings** (not "chapters" or "scenes")
- Use **Entities** (not just "characters")
- Use **cords** and **knots** (not "beats" or "plot points")
- Use domain tags: `hana`, `kay`, `ukhu`
- Begin Weavings with "meeting of presences"; end on "transformation of relation"

## Narrative Spine Elements

These five patterns repeat and evolve across eras—track them in every Weaving (see `THEMES.md` for full details):

1. **Place as Time-Anchor**: Tiwanaku/Akapana stores time; stones are the archive, people temporary readers
2. **Sky as Narrative Drumbeat**: Celestial events (comets, meteors, eclipses) open doors between moments
3. **Runners as Receivers/Relays**: Chasquis carry not just messages but eras; the body in motion carries history
4. **Fire → Seeds**: Catastrophe is inevitable; continuity is chosen and carried forward
5. **Family as History in Miniature**: Empire's violence repeats inside the home until someone interrupts

## Writing Principles

| Do | Don't |
|----|-------|
| Honor silence, pause, and return | Force linear causality |
| Let the land speak through detail | Treat nature as backdrop |
| Allow multiple times to coexist | Collapse events into chronology |
| Write through reciprocity | Center human will or mastery |
| Use sensory language as emotion | Over-explain mystery |
| Weave relationships, not outcomes | Build toward single climax |

## Adding New Content

### New Weaving

1. Duplicate `WEAVINGS/_TEMPLATE.yaml` as `WEAVINGS/WNN.yaml` (sequential numbering)
2. Fill in: `weaving_id`, `domain`, `threads_continued`, `event_form`, `transformation`, `symbolic_motif`, `entities_present`
3. Add a knot to an existing cord (or create new cord) in `KHIPU_MAP.yaml`
4. Run `python update_khipu.py` (or commit to trigger hook)

### New Entity

1. Duplicate `ENTITIES/_TEMPLATE.yaml` as `ENTITIES/entity_[name].yaml`
2. Set `entity_id`, `domain`, `essence`, `relations`, `material_presence`
3. Run `python update_khipu.py`

### Editing KHIPU_MAP.yaml

- Edit `cords`, `knots`, and domain settings manually
- **Never hand-edit** `entities_index` or `weavings_index`—these are auto-generated by `update_khipu.py`

## Custom Agents

## AI Collaboration Guidelines

When drafting:

- Include 150-400 word recap of relevant context before new material
- Declare emotional target and desired shift
- Specify arc (992 Tiwanaku, 1992 Copacabana, 1532 comet, etc.)
- Limit to 900 words per pass; continue with condensed recap
- Do not invent cultural/historical elements without research check—flag as `Requires Fact Check`

### Voice Registers

| Voice | Domain | Tone | Mode |
|-------|--------|------|------|
| Human (protagonist) | Kay | intimate, sensory | dialogue, thought |
| Ancestor/Memory | Ukhu | slow, echoing | dream, ritual fragment |
| Elemental Being | Hana/Kay | cyclic, impersonal | sound, silence, symbol |
| Collective (ritual chorus) | All | rhythmic, shared | chant, pattern |

> Voices are not "characters" but *threads of perception* that braid and unbraid.

### Weaving Structure

- Begin with **meeting of presences** (not exposition)
- Transform a *relation*, not just reveal information
- Allow threads to **recur** in altered forms (echo, inversion, reflection)
- End on *vibration*—something felt across worlds, not resolution

## Story Timeline

The story timeline is not linear. It follows a spiral structure moving inward: 992 → 1992 → 1452 → 1532 → 1492, toward a central pachakuti of Columbus' arrival in the western hemisphere planting the seeds of generational trauma (smallpox, slavery, and other forces that will overturn families, communities, empires and civilizations of the west). Along the path, events from different eras interweave thematically and symbolically.

The narrative spans five primary eras connected by cosmic witnesses:

- **992 CE**: Tiwanaku collapse, Elder's burial, Khunu as witness
- **1992 CE**: Dr. Carlos Mamani and family at archaeological site, meteor shower echo
- **1452 CE**: Chucuito, early chasqui life
- **1532 CE**: Spanish conquest, Chasqui's death, comet as threshold marker
- **1492 CE**: Columbus's arrival, first contact, and the beginning of the end
